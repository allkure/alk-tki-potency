# data/

`alk_tki_potency_dataset_v0.csv` and `alk_tki_potency_METHODS.md` are copies of the files
deposited at **doi:10.5281/zenodo.22914209**, released under CC BY 4.0.

Zenodo is the citable source. The copy here exists so the analysis runs without a network, and
`alkdata.load()` verifies its MD5 against the published value on every load, so a modified or
truncated copy cannot silently change a result.

    alk_tki_potency_dataset_v0.csv   e3d1c306ef16774548cb6b53bd065c99   1,293,612 bytes
    alk_tki_potency_METHODS.md       6494a831b2add85802ec6dceacc153a8       5,633 bytes

The Zenodo record also contains `alk_variant_summary_v0.csv` and `alk_patient_METHODS.md`, the
variant-level clinical linkage. They are not needed by the code here and are not duplicated.
